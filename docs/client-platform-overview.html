Executive Summary

CAGE Drones has built a purpose-designed digital platform that unifies public marketing, pilot training, flight operations, and back-office administration in a single secure web application.

The platform supports the full lifecycle of a professional drone training organisation — from the moment a prospective client discovers CAGE online, through structured classroom and field training, to certificate issuance and public verification. It is tailored to CASA-standard Remote Pilot License (RePL) programmes and specialised industrial pathways including mapping, inspection, and precision agriculture.

Key value proposition: One platform replaces disconnected spreadsheets, email threads, and paper logbooks with a modern, role-based system that scales training delivery while giving administrators real-time visibility across students, flights, bookings, and business inquiries.

Platform Architecture

The application is a modern, cloud-hosted web platform built for reliability, security, and mobile access. It uses industry-standard technologies and stores all data in a secure PostgreSQL database with row-level access controls — ensuring each user sees only what they are authorised to access.

Web applicationResponsive Next.js application accessible from desktop and mobile browsers

Database & storageSupabase (PostgreSQL) with encrypted file storage for course materials and assignment uploads

Digital Flight Logbook

A distinguishing feature of the CAGE platform is its integrated flight operations module. Students log every training flight with structured data that mirrors professional aviation practice:

  • Aircraft assignment from the organisation's register
  • Mission type, location, and GPS coordinates
  • Departure/arrival times, duration, and weather conditions
  • Pre-flight checklist — airspace authorisation, NOTAMs, site survey, battery checks, compass calibration, RTH altitude, emergency briefing
  • Post-flight checklist — power-down, damage inspection, log security, anomaly documentation, storage
  • Status workflow: Planned → In Progress → Completed (or Cancelled)
  • Instructor review status: Unreviewed → Approved / Needs Attention

Certificates & Trust

Upon successful completion of a course, instructors or administrators can issue a Certificate of Completion with a unique serial number, grade, and issue date. Certificates can be revoked if needed, with reason and timestamp recorded.

A public verification page allows employers, regulators, or clients to confirm certificate authenticity by entering the serial number — without requiring a login. Only non-sensitive information is exposed: student name, course title, issue date, grade, and revocation status.

Security & Data Protection

  • Role-based access — three distinct roles with enforced portal separation
  • Row-level security — database policies ensure users access only their own data (students) or data for courses they manage (teachers)
  • Immutable exam attempts — once submitted, exam answers cannot be altered
  • Role change protection — only administrators can change user roles; enforced at the database level
  • Private file storage — course resources and assignment uploads stored in secure, access-controlled buckets
  • No exposed secrets — the application uses only public API keys in the browser; administrative database access is server-side only

Deployment & Operations

The platform is production-ready and configured for cloud hosting with the following operational characteristics:

  • Environment-based configuration for database, authentication, and email
  • Automated build and deploy pipeline (Render Blueprint included in repository)
  • Database migrations managed as versioned SQL scripts
  • First administrator bootstrapped via secure one-time database promotion
  • Optional inline email delivery (Resend) or queued outbox for background processing
